# 🌐 Personal Portfolio Website

A modern, fully responsive personal portfolio website built using **HTML5, CSS3, and JavaScript (ES6)**. This portfolio showcases my skills, projects, and experience as an **Electronics & Computer Science Engineer**, **AI Developer**, and **Full Stack Developer**.

---

## 📖 Project Overview

This portfolio was developed as part of a web development assignment to demonstrate responsive web design, clean UI/UX, and interactive JavaScript features.

The website includes:

* Responsive Navigation Bar
* Hero Section
* About Me
* Skills
* Projects
* Contact Form
* Mobile-Friendly Design
* Smooth Animations

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/portfolio-website.git
```

### 2. Open the Project

```bash
cd portfolio-website
```

### 3. Run the Website

Open `index.html` in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
